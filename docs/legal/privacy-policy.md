# 隐私政策（内部离线草案）

**policy_version:** `privacy-2026-08`
**状态：** 仅用于离线评审；不是已发布的法定隐私通知，也不是法律意见。
**operator_identity_status = unresolved**

运营主体的法定名称、注册地址、隐私负责人和受理邮箱必须由实际运营主体与法务确认后，才能把本文件发布给用户。当前仓库不包含真实姓名、真实邮箱、客户资料或生产数据。

## 1. 我们处理什么

“小象避坑 / ZOUBEACON”提供房产资料整理和风险提示工作流；“小象数据 / ZOUSEEKING”提供带来源标记的区域数据查询和分析预览。我们区分以下数据类别，不把演示或模型结果当作已收集的市场事实：

- **账户身份资料：** Supabase Auth 保存的邮箱、用户 ID、邮箱确认状态和用户 metadata（包括用户名，以及注册时的 `consent_version`、`consent_at`、`terms_version`、固定 `consent_source=registration`）。
- **账户资料：** 用户主动填写的昵称、城市、关注区域、物件类型和备注。会员等级、额度、封禁和审核字段由受信任服务管理。
- **项目资料：** 用户主动提交的链接、文字、PDF、JPG/PNG、结构化字段、证据定位、位置候选地址和报告。私有资料不进入公开内容库。
- **查询与运行记录：** 认证用户自己的查询、生成任务、报告和必要的错误分类。浏览器不得以邮箱作为所有权边界。
- **同意与运营记录：** 政策/条款版本、UTC 同意时间、用途、删除申请、资料主体请求和事故审计记录。
- **公开或模型数据：** 已审核的 `verified_observation`、`scraped_aggregate`、`modeled_estimate`、`synthetic_fixture` 等数据类别，以及来源、期间、版本和限制。

我们不主动收集身份证件号码、My Number、银行卡完整号码、联系人电话或精确住宅地址作为注册条件。用户不得上传不应由平台接收的敏感资料。

## 2. 用途和边界

我们只在相应用途内处理资料：

1. 创建和保护账户、发送密码找回邮件、刷新和撤销会话；
2. 保存用户主动提交的项目资料，生成带证据定位的候选字段和报告；
3. 保存查询任务、结果版本、质量状态和故障分类，以便用户查看自己的工作台；
4. 记录独立的隐私/条款同意证据，处理查阅、更正、删除或投诉请求；
5. 维护安全、限流、审计、备份恢复和服务可靠性；
6. 在用户另行选择并且适用法律允许时发送产品或交易通知。营销同意不替代交易通知，也不替代项目资料用途同意。

模型估算、示例数据和合成夹具必须在界面中标注数据类别、样本量、期间、来源和限制；缺少证据时显示资料不足，不生成确定的法律、税务或投资结论。挂牌与成交、不同地区或不同数据类别不得在一个指标中混算。

## 3. 同意证据

注册前，用户必须分别看到本政策和服务条款并主动勾选。当前 legacy 前端在提交边界生成 UTC `consent_at`，并将以下字段写入 Supabase Auth metadata；用户不能在表单中填写该值，但浏览器时钟和 Auth metadata 仍是不可信输入，正式上线前必须由受信任服务端/Auth 事件补充时间戳核验：

```json
{
  "consent_version": "privacy-2026-08",
  "consent_at": "2026-08-31T00:00:00Z",
  "terms_version": "terms-2026-08",
  "consent_source": "registration"
}
```

示例时间仅说明格式，不是任何用户记录。拍照定位等独立用途使用单独版本（例如 `location-2026-08`），不能用注册同意替代。撤回同意后，停止相应可选用途；依法必须保留的审计或财务记录只做受限保存，不再用于营销或撮合。

## 4. 处理方、共享和跨境

当前预期的基础设施为 Supabase Auth、Supabase PostgreSQL、私有 Supabase Storage、Render FastAPI 和受审计的后台 worker；实际供应商、地区、子处理者清单和跨境机制必须由运营主体在发布前确认。目标架构是由 FastAPI 授权私有 profile、project、query、report、consent、audit 数据；但旧区域路径的 `web/app.js` 在配置存在时仍可能直连 Supabase REST/Edge Function。这一架构冲突尚未收敛，是上线 blocker，不能把目标描述当作当前 production 控制。

只有为完成用户请求、维护安全或履行法律义务所必需时，才向受约束的服务商、工作人员或依法有权的机构披露。不同数据主体、处理地区或接收方所在地区之间的联系信息交换，需要独立授权和适用的跨境机制；未完成法律审核前不开通。

## 5. 保留和删除

下表是内部目标，不代表已在 staging 或 production 强制执行：

| 数据 | 目标保留 | 删除/匿名化规则 |
| --- | --- | --- |
| 未转正的匿名 intake 会话与私有文件 | 会话创建后 24 小时（清理窗口最多再延 5 分钟） | 到期后拒绝读取，并由受信任清理器删除对象；Render Free 休眠可能使墙钟 SLA 未达成 |
| 账户 profile、项目资料、查询和报告 | 账户有效期 | 账户删除申请受理后，主数据目标 30 天内删除或不可逆匿名化 |
| 当前登录会话/刷新令牌 | 账户有效期或撤销 | 登出/撤销后停止使用；过期或失效令牌不得重用 |
| 同意、删除、DSAR、投诉和事故审计 | 账户关闭后 3 年，或适用法律要求的更长期间 | 仅限受审计人员访问；到期删除或匿名化 |
| 备份中的个人资料 | 主数据删除后最多 90 天 | 通过备份轮换自然到期；不能用备份恢复覆盖已执行删除 |

法律保留、争议、欺诈调查或财务义务可以暂缓指定记录删除；我们会记录范围、原因、复核日期和解除后的删除动作。删除账户不等于删除对方已复制的内容，也不等于取消独立订阅/付款义务。

## 6. 资料主体权利和客服

资料主体可以通过 [客服入口](../../web/support.html) 请求查阅、更正、删除、限制、反对或获取可移植副本。我们会在必要时要求最小化的身份验证，避免因冒用请求泄露资料。内部目标是 24 小时内确认收到、30 天内完成或说明合法延期；实际法定期限以适用法律和运营主体确认的身份为准。

当前客服地址 `support@zouseeking.example` 是保留域名占位，不会向真实收件箱发送通知；上线前必须替换并完成访问控制、工单留痕和删除 SLA 监控。

## 7. 安全与事故

目标控制包括最小权限、服务端所有权检查、私有对象、账户与滥用来源限流、结构化日志、令牌不入日志、备份恢复和事故响应流程；其中限流、恢复和删除执行器尚未完成 production 验证。现有静态前端仍有 localStorage 本地登录回退和 token 存储风险；该路径只可作为演示，完成受信任 Auth/会话迁移前不得声称 production 安全。

疑似泄露按 [事故响应流程](incident-response.md) 分级、遏制、保留证据并进行通知决定。是否向资料主体、监管机构、供应商或其他方通知，须由运营主体与法务依据适用法律和事实确认；离线测试不发送通知。

## 8. 变更和官方参考

政策版本、用途、处理方、跨境机制或保留规则变化时，应发布新版本并重新取得必要同意。日本个人信息保护委员会（PPC）的 APPI 原文和译文说明仅作为参考，原文具有法律效力：[PPC Laws and Policies](https://www.ppc.go.jp/en/legal/)、[APPI 参考译文](https://www.ppc.go.jp/files/pdf/APPI_english.pdf)。本草案不替代运营主体针对日本、欧盟、香港或其他地区的正式法律审查。
