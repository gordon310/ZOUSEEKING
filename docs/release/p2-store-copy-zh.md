## 短描述(≤80 字符)

看日本房子前,先让小象帮你查成交价与买房成本。

## 完整描述(建议)

**小象避坑(ZOUBEACON)**——在日本看房、买房前的资料整理与核查小助手。

**怎么帮你避坑**
- 📷 拍照或上传资料,小象整理物件关键信息:类型、面积、地址、土地权利等
- 🔍 免费预览:资料完整度一目了然,购入费用(中介手续费、印花税、登记税等法定项)按官定口径给确定性估算
- 📊 市场可比:同区中古公寓成交均价参考(1LDK/2LDK/3LDK),数据来自日本国土交通省取引价格信息(出所明記)
- 📄 深度报告:成交参考明细、汇率注记与数据口径,一次解锁本账号全部报告
- 💾 资料与查询保存在你的账户下,随时回看

**数据与合规说明**
- 成交参考数据来自日本国土交通省《土地総合情報システム》取引価格情報(政府开放数据,标注出处)
- 报告中的人民币/美元换算仅作显示参考,汇率注记来源与日期见报告
- 免费预览与深度报告不是完整估价、税务意见或法律结论;关键决策请以专业机构意见为准
- 我们不做无授权抓取;租赁相场等未获授权数据源在获得许可前不对外输出
