# ZOUBEACON 认证前置与流程修复计划

## 目标

让 ZOUBEACON 的分析入口先完成注册/登录，再创建分析会话和生成资料检查结果；项目页展示当前用户的真实查询项目；修正文案、保存后的导航和 PWA 离线资源，使用户能沿着“注册/登录 → 新建分析 → 资料检查 → 保存项目 → 查看进度/报告”的单一路径操作。

## 实施步骤

1. 为匿名创建分析会话、匿名前端入口、照片文案和真实项目列表补充失败测试；验证测试确实先失败。
2. 在 FastAPI 会话创建接口绑定认证用户，并在前端分析入口增加认证门槛；保留已认证用户的资料检查接口和会话恢复能力。
3. 将项目页从硬编码演示项目改为读取 `/api/my/queries`，仅在显式 `?demo=1` 时展示演示数据；修正 C 端导航和保存后的项目进度链接。
4. 更新照片临时保存说明、状态提示和多语言文案，避免把私有存储描述成“不存储”。
5. 扩充 service worker 的 C 端离线资源清单，并放宽版本号解析以兼容构建后的压缩脚本；增加真实 service worker 离线回归测试。
6. 运行生成资源构建、静态检查、Python/API 测试、前端 Playwright 和 PWA 专项测试，记录仍受外部 staging 服务状态影响的项目。

## 验收标准

- 未登录用户不能创建分析会话，也不能进入资料检查预览；页面提供注册/登录入口和返回路径。
- 已登录用户可以创建会话、提交资料检查并保存项目；保存后能看到项目进度入口。
- `/api/my/queries` 的真实结果能在项目页显示；没有数据时显示空状态，未登录时显示认证入口，演示数据只由 `?demo=1` 显式开启。
- 照片说明与实际私有临时存储行为一致。
- PWA 安装后可从缓存加载分析页及其脚本/样式，版本检测兼容构建产物。
- 相关测试全部通过，生成文件校验通过；不宣称外部 staging 已恢复或生产已发布。
