# 小象数据首页、会员管理与三语界面设计规格

**状态：** 已由产品方确认，2026-08-28

## 目标

让小象数据的 B 端入口更像一个紧凑的登录后工作台：主页只负责进入系统和查看最近更新，数据查询进入独立页面；后台增加会员管理入口；数据查询、统计分析、数据与服务工作台统一支持中文、英文和日文。

## 角色范围

- C 端：小象避坑，面向 app / 小程序 / 网页用户，保持引导优先和较多留白。
- B 端：小象数据，面向数据查询、统计分析和服务协作人员，使用紧凑工作台布局。
- 管理员：工作人员后台，面向采集、质量、发布、服务派单和会员运营，使用表格优先的紧凑布局。

本规格只改静态演示界面和本地演示交互，不改变真实认证、数据库、RLS、会员资料或会员权限。

## 页面信息架构

### 小象数据主页 `web/index.html`

保留：

- B 端品牌和主导航。
- 登录、注册、找回密码和退出区域。
- 简短的工作台欢迎区。
- 登录区域正下方的紧凑“最近更新内容”列表。

移除：

- 首页数据查询表单。
- KPI 概览卡片。
- C 端服务任务卡片。

最近更新列表每条记录只显示 `¥`、记录名称和小号的时间/地区信息，不渲染封面图片。列表仍可在登录后打开详情；数据记录内容继续由本地 content library 提供，不能把演示记录当作实时生产数据。

桌面端中，账户区位于左侧，最近更新紧接在账户区下方；欢迎区位于右侧。移动端恢复单列，顺序为账户、最近更新、欢迎区。

### 数据查询 `web/data-query.html`

新建独立 B 端页面，承接原首页的地区、物件类型、年份、月份筛选、查询历史、分页、生成进度、结果列表和详情返回。主导航的“数据查询”统一指向此页面。页面继续使用现有 `app.js` 查询逻辑和本地/远端数据边界。

### 统计分析 `web/analysis.html`

保留现有趋势、比较和分析状态，统一接入语言切换器、导航、账户壳、表单标签、按钮和状态文案。

### 数据与服务工作台 `web/mypage.html`

保留现有查询任务、项目和服务任务状态，统一接入语言切换器、导航、账户壳、状态文案和空状态。

### 管理员后台 `web/admin.html`

在现有“总览 / 采集任务 / 质量审核 / 服务派单”中增加“会员管理”模块。会员模块使用明确标记的 `synthetic_fixture` 本地演示行，展示会员名称/脱敏标识、等级、状态、额度使用、最近活动和详情操作。搜索、状态筛选、查看和暂停/恢复只更新当前页面演示状态，不写入数据库。

管理员和账户页也放置同一语言切换器，以免 B 端从三语页面跳转后界面语言突变；本轮优先翻译界面 chrome，演示数据记录、地名、会员演示姓名和数据内容保留原始语言。

## 多语言交互

- 支持 locale：`zh-CN`、`en`、`ja`。
- 新增共享 `web/js/i18n.js`，使用 `localStorage` 键 `zou_ui_locale` 保存选择，默认中文。
- 页面载入时根据保存的 locale 更新 `document.documentElement.lang`、静态 `data-i18n` 文本、placeholder、aria-label 和页面标题。
- 语言切换器使用原生 `<select>`，选项显示“中文 / English / 日本語”；切换后刷新当前页面，确保由 `app.js` 动态产生的界面也采用相同 locale。
- 未翻译的业务数据不伪造翻译；它们按来源语言显示，并继续遵循 provenance/data class 规则。

## 设计系统约束

- 继续沿用现有 ZOUSEEKING 深蓝、暖橙、白色表面、细边框和紧凑 B 端布局。
- B 端桌面控件使用现有紧凑字号，手机输入框保持至少 `16px`，触控目标至少 `24x24px`。
- 主页最近更新是无图片的开放列表，不新增图片占位、卡片网格或额外 KPI。
- 所有表单控件保留可见 label、键盘焦点和 `aria-live` 状态。
- 设计仅使用现有静态 HTML/CSS/JavaScript，不引入 React、Vite 或新依赖。

## 验收标准

1. `index.html` 不包含首页查询表单、概览 KPI 和服务任务区，最近更新紧接登录区且无图片。
2. `data-query.html` 可以打开，B 端导航、查询表单、结果列表、详情和返回动作可用。
3. `analysis.html`、`mypage.html`、`data-query.html` 切换三种语言后，导航、标题、主要标签、按钮和提示文案随语言更新。
4. `admin.html` 可以打开“会员管理”，搜索、状态筛选、查看和本地暂停/恢复有可见反馈，并标示演示数据。
5. 桌面端没有不必要的宽表单或横向溢出，`390x844` 下没有横向滚动，键盘焦点可见。
6. 不执行真实会员写入、数据库 migration、RLS 修改或认证策略修改。
