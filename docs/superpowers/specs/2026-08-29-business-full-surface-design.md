# 小象数据完整 B 端页面设计规格

**状态：** 用户已确认实施

**日期：** 2026-08-29

## 1. 目标

在现有“小象数据 / ZOUSEEKING”核心页面之外，补齐 B 端用户可以理解和评审的业务闭环页面：机构与成员、套餐与账单、用量与额度、统计订阅、数据导出、服务任务池。

本轮只做静态前端和本地演示状态，沿用现有 `styles.css`、`business.css` 的 navy/orange 视觉系统，支持中文、英文、日文，不接入真实会员、支付、额度或任务数据。

## 2. 页面范围

| 页面 | 路由 | 主要用途 | 本轮交互 |
| --- | --- | --- | --- |
| 机构与成员 | `organization.html` | 查看机构、席位、成员角色和合作方状态 | 邀请成员演示、查看成员详情 |
| 套餐与账单 | `billing.html` | 查看 B Free / B Data Pro 权益、价格、续费和账单 | 切换币种、模拟选择套餐、模拟取消自动续费 |
| 用量与额度 | `usage.html` | 查看机构共享的查询、分析、订阅和导出用量 | 切换用量分类、查看演示事件 |
| 统计订阅 | `subscriptions.html` | 管理按条件保存的统计更新订阅 | 暂停/恢复、删除、添加演示订阅 |
| 数据导出 | `exports.html` | 选择数据集、格式和条件，查看导出任务 | 创建本地演示导出任务、查看完成项 |
| 服务任务池 | `service-tasks.html` | 浏览 C 端陪同看房、专家分析和好房推荐需求 | 状态筛选、查看详情、申请/撤回演示任务 |

已有页面继续保留：`index.html`、`data-query.html`、`analysis.html`、`mypage.html`、`profile.html`。管理员继续使用独立的 `admin.html`，不把管理员操作混进 B 端页面。

## 3. 共享页面壳

- 页面顶部复用小象数据品牌、核心导航、语言选择器和“账户资料”入口。
- 新页面使用紧凑的 B 端工作区：桌面为左侧账户/状态栏加右侧主工作区，手机恢复单列，表格允许在组件内部横向滚动。
- 每页只有一个明确主操作；涉及真实后端的按钮显示“演示”或“尚未接通”，不会发送请求。
- 每个页面显示 `synthetic_fixture` 或“仅本地演示”提示，禁止把演示机构、价格、用量和任务描述呈现为真实业务数据。
- 界面文案和动态状态统一通过 `web/js/i18n.js` 的 `zh-CN`、`en`、`ja` 字典处理；来源数据中的日本地区和记录名称保留原文。

## 4. 交互边界

- 机构页的邀请和查看只改变当前页面提示，不创建账户、不发送邀请邮件、不修改席位。
- 账单页的币种切换只切换预置 CNY/JPY/USD 展示；套餐选择和自动续费按钮只改变演示状态，不打开支付、不保存支付方式。
- 用量页只展示固定的机构共享额度和事件记录，不允许浏览器写入额度。
- 订阅页的暂停、恢复、删除和添加只操作页面内夹具；不创建定时任务、不发送邮件。
- 导出页只创建本地演示任务，完成项可查看状态但不下载真实数据集。
- 服务任务池不展示姓名、邮箱、电话、精确住宅地址或原始附件；申请和撤回只改变演示状态。

## 5. 响应式与可访问性

- 验证尺寸：桌面 `1440x900`，移动 `390x844`。
- 所有表单控件有可见标签；按钮和链接保持键盘可达并保留 `:focus-visible`。
- 表格在窄屏通过内部滚动容器展示，不让 `document.documentElement` 横向溢出。
- 空状态、状态提示和演示说明保持可读，颜色不作为唯一状态表达。

## 6. 验收标准

1. 6 个新路由可从评审入口访问，页面标题、导航和语言选择器可用。
2. 每个页面至少有一个可验证的本地交互，并明确不写入真实后端。
3. 中文、英文、日文切换后，当前页面的标题、导航、核心操作和状态文案同步更新。
4. 桌面和移动端无横向溢出；控制台无 page error 或应用级 console error。
5. 仓库内 Playwright 用例覆盖 6 个路由和关键操作；全量 Web 回归保持通过。

## 7. 非目标

- 本轮不创建机构、成员、订阅、支付、用量、导出或任务数据库表。
- 本轮不修改 Supabase RLS、Auth、支付 webhook、真实额度计量或后台权限。
- 本轮不把 `app.js` 扩展成新的全局控制器；新页面交互放在独立的 `business-pages.js`。
