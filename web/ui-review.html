01 · 小象避坑

C 端 · 引导优先

面向 app / 小程序 / 网页用户，提交物件资料、查看免费预览和完整报告，并发起陪同看房、人工专家分析或好房推荐。

提交资料 / 免费预览用途选择、资料上传、字段确认、风险和费用预览 我的项目项目列表、资料完整度、下一步动作 报告工作台完整报告、历史版本、补充资料和失败恢复 账户资料账户、安全设置、隐私与服务条款入口
权益已准备生成中生成失败补充资料

02 · 小象数据

B 端 · 紧凑协作

面向数据和服务协作人员，查询公开数据、查看统计分析，也可以接收和推进 C 端服务任务。

数据查询入口地区 / 物件类型 / 年月筛选、结果列表和详情 统计分析趋势、横向比较、样本数和限制说明 数据与服务工作台查询任务、生成状态和个人协作入口 账户资料账号、安全设置和只读会员信息 机构与成员机构席位、成员角色、合作方状态和邀请演示 套餐与账单B Free / B Data Pro、币种、自动续费和账单记录 用量与额度机构共享的查询、分析、订阅和导出计量 统计订阅保存区域与物件条件，暂停、恢复或删除订阅 数据导出选择公开数据集、格式和行数，查看导出队列 服务任务池浏览陪同看房、人工专家分析和好房推荐任务

03 · 后台维护

管理员 · 最紧凑

面向工作人员，维护授权数据采集、数据质量、发布门槛和 C 端服务派单；不与 C/B 端混用。

数据运营总览采集任务、质量审核、发布前检查和服务派单 采集任务数据源、数据类、运行状态和重试入口 质量审核来源、期间、单位和建模版本的阻塞项 会员管理会员状态、额度和演示操作；不写入真实会员资料
本轮确认重点：请先确认三种角色的入口、信息密度、按钮命名和跨角色跳转。C 端保持易懂和留白，B 端/管理员可以更紧凑；逐屏确认后再调整数据结构、migration 和测试数据。
